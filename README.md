# Contador de Cédulas e Moedas

## Descrição do Projeto
Este programa calcula a quantidade mínima de cédulas e moedas necessárias para pagar um determinado valor em reais. O sistema considera todas as cédulas e moedas do sistema monetário brasileiro.

## Céduas e Moedas Suportadas
Cédulas: R$200, R$100, R$50, R$20, R$10, R$5, R$2.
Moedas: R$ 1.00, R$0.50, R$0.25, R$0.10, R$0.05.
